# JavaDex | Guia de Estudo de Java

O JavaDex é um site de estudo criado para ajudar a aprender e rever Java de forma simples, organizada e prática, com teoria direta, exemplos de código, exercícios, quizzes e ferramentas de apoio ao estudo.

## Visão Geral

Este projeto é um guia interativo de Java que permite:
- Estudar os principais conceitos da linguagem Java
- Seguir uma ordem recomendada de estudo
- Ler explicações curtas e focadas
- Ver exemplos de código
- Resolver exercícios diretamente no browser
- Fazer quizzes de revisão
- Guardar notas pessoais
- Acompanhar o progresso de estudo
- Usar checklist de preparação para exame
- Alternar entre modo claro e modo escuro

## Tecnologias

- **HTML5**: estrutura principal do site
- **CSS3**: estilos, layout responsivo, temas e componentes visuais
- **JavaScript**: interatividade, progresso, quizzes, exercícios, notas, pesquisa e flashcards
- **Node.js**: servidor local simples para correr o site

## Estrutura do Projeto

```bash
javadex/
├── index.html
├── server.js
└── README.md
```

## Como Abrir

O site pode ser visualizado diretamente através do GitHub Pages:

```text
https://nashi34.github.io/javadex/
```

Também pode ser aberto localmente de duas formas:

1. Abrir o ficheiro `index.html` diretamente no navegador
2. Ou usar o servidor local com Node.js:

```bash
node server.js
```

Depois abrir no navegador:

```text
http://localhost:3000/
```

Também pode ser usado o Live Server do Visual Studio Code para testar o site de forma rápida.

## Funcionalidades

### Página Inicial
- Apresenta o objetivo do JavaDex
- Mostra a ordem ideal de estudo
- Explica como usar o site
- Ajuda a preparar o estudo até ao exame

### Lições de Java
- Conteúdos organizados por tópicos
- Explicações curtas e diretas
- Exemplos de código
- Avisos sobre erros comuns
- Resumos para revisão

### Exercícios
- Exercícios práticos por tema
- Área para escrever código
- Validação simples no browser
- Feedback para ajudar a corrigir respostas

### Quizzes
- Perguntas de revisão no final das lições
- Respostas com feedback
- Apoio na consolidação dos conceitos principais

### Progresso
- Marcação de lições concluídas
- Percentagem de progresso
- Checklist de preparação para exame
- Opção para limpar progresso e recomeçar

### Ferramentas de Estudo
- Pesquisa por tópicos
- Flashcards rápidos
- Bloco de notas pessoal
- Modo claro e modo escuro

## Estado do Projeto
